Säkerköping – Ett spel om ångest

Säkerköping is a prototype for an educational game about anxiety, developed in collaboration with BUP Skåne and aimed at adolescents.
The game uses a fictional town and its inhabitants to introduce concepts related to anxiety and coping strategies through exploration, dialogue and interactive gameplay.

Project

The game was developed as part of a university project in collaboration with psychologists from BUP Skåne. Development focused on creating an engaging and accessible way of communicating information about anxiety to young people.
The project was developed by a team of three students and included three structured workshops with students at different schools. Feedback from these workshops was used to evaluate and further develop the game.

Team

The project was developed by three students:

Gabriel – Programming, progression and gameplay systems

Victor – Graphics, programming, camera movement and POI system

Olle – Programming, initial dialogue system implementation

Technologies

Unity
C#
Git

User Testing

The game was evaluated through three structured workshops with students from different schools.
The workshops provided feedback on the game's usability, communication and overall experience, which was used to inform further development.

Current Status

The game can currently be run from the Unity Editor.
Gabriel and Victor are currently working on preparing the game for release on iOS and Android through the App Store and Google Play.
